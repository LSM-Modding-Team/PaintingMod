Temporary archive of the fifteen disabled paints: original registrations, palette,
sanding/refund logic, models, textures and translations. This directory is outside
Gradle's main Java and resource source sets and is not included in the mod or sources JAR.

In the active palette version 2, checker is ID 1 and vanilla paints occupy 2..338.
The fifteen archived paints have reserved IDs 339..353, preserving their original
order. They have no registered items or loaded textures and render as unpainted.
Readers identify legacy palette data explicitly and preserve its old meaning.
See catalog/paint-id-conversion.csv for the original-to-current mapping.

Archived Java files are reference snapshots, not an alternative active source set.
Re-enabling them requires updating names and registrations in the active implementation.
